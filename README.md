# Arc-Like-Game 戦闘プロトタイプ

HTML/CSS/JavaScriptで作成した、タクティカルRPGの戦闘プロトタイプです。

## 実装済みの内容

- 16×16マスの草原マップと味方・敵の配置
- 素早さ順のキャラクター単位のターン進行
- 味方の移動、通常攻撃、回復薬の使用、待機
- ターン開始時に固定した移動可能範囲の中で、位置を何度でも選び直し可能
- 攻撃・アイテムの対象決定、または待機で移動位置を確定
- 移動可能マスのみの単色ハイライト
- 移動アニメーション、行動キャラを中心に戦場全体を拡大するカメラ演出
- 敵の移動・攻撃AI
- HP管理、戦闘不能、勝利・敗北判定
- 戦闘開始時のマップ周回カメラ演出
- 敵撃破者への経験値付与、レベルアップと能力値上昇
- 戦闘結果画面での経験値・レベルアップ数・賞金の表示
- 再戦時も維持される味方の成長と所持金

## 操作方法

- ターン開始時に移動可能マスが表示されます。移動可能マスをクリック／タップして、移動位置を何度でも選び直せます。
- 「攻撃」を選んで隣接する敵のマスをタップするか、「アイテム」を選んで回復する味方のマスをタップすると、移動位置が確定して処理されます。
- 「待機」を押すと、その時点の位置で行動を終了します。位置を変えずに攻撃・アイテム・待機を選ぶこともできます。
- 回復薬はHPを最大10回復し、初期所持数は3個です。
- 敵の行動中は操作できません。
- 戦闘開始時のマップ紹介演出後に行動が始まります。
- 敵を倒すと、撃破したキャラクターだけが経験値を獲得します。累計経験値がレベル×50に達するごとにレベルが上がり、最大HP・現在HPが5、攻撃力・防御力が1増加します。
- 戦闘終了時に倒した敵の賞金をまとめて獲得します。結果画面の「もう一度戦う」から再戦すると、味方の成長と所持金は引き継がれます。

## 起動方法

プロジェクトフォルダで次を実行し、ブラウザで `http://127.0.0.1:8000` を開きます。

```bash
python3 -m http.server 8000
```

停止するときはターミナルで `Ctrl + C` を押してください。
